## English

A bilingual WebAR application (English/Chinese) built with **React** and **Mind-AR**, featuring interactive video triggers for 11 unique QR codes. Co-developed using AI automation tools.

### 🚀 Live Demo & Links
* 📱 **WebAR Application**: [Click here to experience](https://intheothesideofthemoonntut.netlify.app)
* 🌐 **Official Website (About)**: [Click here to visit](https://intheothersideofthe-moon.netlify.app/#about)
* 🥽 **Sister Project (Meta Quest 3 MR Version)**: [View MR Repository](https://github.com/TSESHITING/your-mr-repo-name) ### 💡 About The Project
This web-based AR application provides a lightweight, no-install-required empathy experience. By scanning 11 unique QR codes via a mobile browser, users can trigger interactive videos that vividly illustrate the visual confusion and daily struggles faced by children with learning disabilities.

### 🛠️ Tech Stack
* **Frontend Framework:** React / Vue
* **AR Engine:** Mind-AR (Image Tracking)
* **Automation:** AI-assisted development tools
